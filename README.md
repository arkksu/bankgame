# Банковская игра — автономная версия (HTML/CSS/JS)

Игра работает **без Python и без сервера**: чистые HTML, CSS и JavaScript,
данные партий хранятся в `localStorage` браузера. А еще проект полностью 
сделан с помощью нейросети.

## Как запустить

1. Откройте `index.html` двойным кликом (браузер разрешает такие страницы —
   скрипты подключены обычными `<script>`, без модулей).
2. На стартовом экране слайдером выберите число команд (2–6) и нажмите
   **Новая игра**. *Имена команд генерируются автоматически
   (Команда 1, Команда 2 и т.д.).*

## Новые вкладки

На странице есть навигационные кнопки (Игра, Команды, Рынок, Колода,
События, Справка). Их поведение:

- **Игра** — возвращает к текущему ходу игры, отображает шапку с расходом,
  кнопкой «Бросить кубик» и панелью управления. Кнопка активна всегда.
- **Команды / Рынок / Колода / События / Справка** — заменяют основной контент
  на панель осмотра. Кнопка соответствующей вкладки становится активной (имеет
  серый ободок). Нажатие вне панели или на кнопку «Решение ЦБ» закрывает её.
- **Решение ЦБ** — всегда работает как всплывающее окно (по кнопке в шапке
  и пункте меню), независимо от выбранной вкладки.

Панель закрывается крестиком или кликом в любом месте экрана; панели
взаимоисключающие (открывается новая — старая закрывается).

## Что где лежит

| Файл | Назначение                                            |
|---|-------------------------------------------------------|
| `index.html` | разметка (стартовый экран, шапка, панели, управление) |
| `style.css` | стили (общие с веб-версией на WebSocket)              |
| `config.js` | стартовые значения и параметры партии (`START_CONFIG`) |
| `cards-data.js` | данные карточек, встроенные из `cards.json`           |
| `engine.js` | движок партии                                         |
| `ui.js` | мост «экран ↔ ответ»: движок ждёт ответ через Promise |
| `storage.js` | сохранение партии и истории в `localStorage`          |
| `app.js` | рендер экранов, кнопки, панели осмотра                |

Ключи хранилища: `bankgame.save.v1` (незавершённая партия),
`bankgame.results.v1` (история итогов, до 50 записей).

## Стартовые значения

Все параметры новой партии вынесены в `config.js` (`START_CONFIG`):

```js
rounds: 6,                 // длительность партии
starting_capital: 10,      // стартовый Капитал команды
starting_liquidity: 15,    // стартовый Баланс команды
discount_cards: [0, -1, -2, -3, -4, -5],
capital_exchange_rate: 2,  // 2 Баланса → 1 Капитал
risk_line_max: 25,         // норматив Риска
auction_lots_extra: 1,     // лоты на торгах сверх числа команд
free_deal_copies: 2,
auction_deal_copies: 2,
pro_deal_copies: 1,
```

В интерфейсе величина `starting_liquidity` называется **«Баланс»**, чтобы её
не путали с Капиталом. В коде по-прежнему используются имена `liquidity`
и `tp-liq` — это внутренние идентификаторы, менять их не нужно.

`config.js` подключается в `index.html` **до** `cards-data.js` и `engine.js`:
`CardDB.load()` объединяет `START_CONFIG` с данными карточек.

## Карточки скидки

Набор карточек задаётся в `config.js` (`discount_cards`). Количество любое:
значения можно добавлять и убирать, строгого требования «ровно 6» больше нет.

Механика торгов:

- команда выкладывает карточку — она сразу убирается из руки (`bid_used`);
- победитель получает сделку с этой скидкой (скидка учитывается при выплате);
- проигравшие карточку обратно сразу **не** получают;
- в конце раунда все использованные карточки возвращаются в руку, то есть
  снова доступны в следующем раунде.

Бесплатные сделки у ЦБ карточки скидки не тратят.
